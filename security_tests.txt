# SQL INJECTIONS
Pour la bdd, j’utilise uniquement l’ORM Django (pas de SQL brut). Il génère des requêtes paramétrées,
donc les entrées utilisateur sont traitées comme données et ne peuvent pas injecter de SQL.

# XSS PROTECTION
Côté XSS, le frontend React/Next.js affiche les données utilisateur comme texte échappé, donc même si quelqu’un met du <script>,
il n’est jamais exécuté, juste affiché.
